YOUR DATA, EXPLAINED.

Privacy policy.

Updated October 18, 2026 · Applies to version 1.4.0

Your selected messages are processed in your browser and saved to files you control. The extension has no developer-operated export server, advertising, or analytics.

Information the extension handles

InformationPurpose and destination
API token you enterSent directly to Discord in the Authorization header to authenticate API requests. Never sent to the project’s maintainer.
Current server and channel identifiersRead from Discord tab URLs to preselect your conversation. Stored in browser session storage when available, with a local-storage fallback.
Servers, channels, message text and metadataRetrieved directly from Discord to populate selectors and create the export you request. Messages are formatted in memory and passed to your browser’s download manager.
Downloaded filesStored wherever you save them. They can contain sensitive message content, author identifiers, timestamps, attachment URLs, reactions, and reply references.

Storage and deletion

The token is kept in browser session storage where supported. Session storage is cleared when the browser session ends and can be cleared earlier using Clear in the popup. If session storage is unavailable, the extension uses local extension storage and tells you so in the popup. In that case the token persists until you clear it or remove the extension.

The extension does not intentionally retain message history after formatting the download. It does not synchronize tokens or exports using browser sync. Clearing the token or uninstalling does not delete previously downloaded files. Delete those through your device’s file manager.

Network access and sharing

The extension makes requests to https://discord.com to perform the actions you request. Requests omit cookies and authenticate using your supplied token. The extension never reads or extracts Discord cookies, page storage, or session credentials.

There is no sale of personal information, advertising use, analytics, or transmission of exports to the maintainer. Discord processes API requests under its own privacy policy. If you open a link contained in an export, that destination may receive information directly from your browser.

Browser permissions

Storage keeps your explicitly provided token and current conversation context. Downloads saves requested export files. Active tab and tabs identify the current Discord channel, track navigation, and open the export workspace. Host access to https://discord.com allows direct API requests and channel URL detection. Other websites are not accessed for exporting.

Website and support

These public pages are hosted on GitHub Pages without project analytics, third-party fonts, tracking scripts, or account forms. GitHub may process connection information as the hosting provider under its privacy statement. Support requests you choose to post on GitHub are public and subject to GitHub’s policies. Never include a token or private messages in a report.

Questions and changes

Contact the maintainer through the project issue tracker for general privacy questions, without including personal data. Changes to this policy will be published here with an updated date. Review the source code for implementation details.
