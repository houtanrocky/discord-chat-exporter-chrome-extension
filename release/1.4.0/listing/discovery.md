# Discovery and launch notes

The title starts with the task users look for: Discord Chat Exporter. The summary names the supported formats, direct messages, date range, bulk export, and progress. The body explains real use cases naturally. Avoid repetitive keyword lists, rankings, fake testimonials, competitor names, or unverified “best”/“official” claims. Store placement is not guaranteed.

Website discovery:
- Unique titles and useful descriptions for homepage, support, and privacy pages.
- Canonical project URLs, Open Graph metadata, a social preview, and SoftwareApplication structured data without invented ratings or installs.
- Accessible HTML, local assets, mobile layouts, and links to the actual listing and public source.
- Submit sitemap.xml to Google Search Console after verifying the published site. Search Console verification requires the publisher account; no fabricated verification token is included.
- robots.txt in a GitHub project subdirectory does not control the github.io origin; it is provided as a deployment aid. These pages have no indexing restrictions.
- GitHub repository About: set the homepage URL and a concise description; suggested topics: discord, chrome-extension, chat-export, csv, json, wxt, firefox.

After launch:
- Verify all public links before adding them to the store.
- Choose the most useful screenshot as the first image; use all five in the documented order.
- Offer honest support and collect feedback. Ask actual users for candid reviews without incentives.
- Monitor actual store impressions, installs, and support issues. Improve the listing based on evidence.

Optional video storyboard (not required for upload):
0–5 s: Open the actual popup on a synthetic channel.
5–10 s: Show format and UTC date selection; keep the token masked.
10–18 s: Start export and show real progress.
18–25 s: Show completion and the downloaded file in a text editor.
25–30 s: End with the product name and support URL.
A YouTube URL must point to a real uploaded video; no placeholder URL is supplied.
